# RakaMod Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build RakaMod 0.1.0, an EllesmereUI companion that adds an Escape overlay, player-frame reveal, zone text, a full AFK screen, and a two-color health gradient on Forever and retail.

**Architecture:** One addon folder is the git repo under `_forever_`. Retail loads it through the existing junction. Pure decisions live in `Logic.lua` and are tested with Lua 5.4 outside the client. Each feature is a module registered with `Core`, reads `RakaModDB`, and does nothing when its Ellesmere module is missing.

**Tech Stack:** WoW Lua addon, TOC interfaces `120105` and `16001`, Lua 5.4 (`DEVCOM.Lua`) for out-of-game tests, Inter font (SIL OFL), a generated white TGA statusbar.

## Global Constraints

- Repo path: `D:\Blizzard\World of Warcraft\_forever_\Interface\AddOns\RakaMod`
- Retail junction already points at that folder. Do not create a second copy.
- TOC: `## Interface: 120105, 16001`, `## Title: RakaMod`, `## Author: Raka`, `## Version: 0.1.0`, `## SavedVariables: RakaModDB`, `## Dependencies: EllesmereUI`, `## OptionalDeps: EllesmereUIUnitFrames, EllesmereUIRaidFrames, EllesmereUINameplates, EllesmereUIDataBars, LibSharedMedia-3.0`
- Forever means `select(4, GetBuildInfo()) == 16001`. Do not use `WOW_PROJECT_ID`.
- KryoMOD and ToxiUI are behavior references only. Do not copy their files, fonts, or art.
- Addon license stays All Rights Reserved. The font license in `Media/OFL.txt` covers Inter only.
- Mythic+, group finder, Hero's Path, and Raider.IO are out of this version.
- Gradient default is off. Colors are one pair, left to right: `(0.91, 0.84, 0.64)` to `(0.15, 0.14, 0.13)`.
- Do not write Ellesmere saved variables.
- Missing APIs hide a row or panel. No Lua error.
- Secret health values skip that health check.
- In-game behavior is verified with the manual checklist in the spec. Out-of-game tests cover `Logic.lua` only.

Module definition shape:

```lua
{
  name = "Overlay",
  dbKey = "overlay",
  requires = "EllesmereUIUnitFrames", -- or nil
  OnLoad = function(self) end,
  OnEnable = function(self) end,
  OnDisable = function(self) end,
}
```

`RegisterModule` calls `OnLoad` immediately. It calls `OnEnable` only after `PLAYER_LOGIN`, and only when `RakaMod.db[dbKey].enabled` is true and `requires` is either nil or loaded. Otherwise it does not call `OnEnable`. A later settings change calls `OnEnable` or `OnDisable` to match the switch.

- [ ] **Step 3: Write `Logic.lua`**

```lua
local Logic = {}

function Logic.CopyTable(value)
  if type(value) ~= "table" then
    return value
  end
  local out = {}
  for key, child in pairs(value) do
    out[key] = Logic.CopyTable(child)
  end
  return out
end

function Logic.MergeDefaults(saved, defaults)
  if type(saved) ~= "table" then
    saved = {}
  end
  local out = {}
  for key, defaultValue in pairs(defaults) do
    local current = saved[key]
    if type(defaultValue) == "table" then
      if key == "played" and type(current) == "table" then
        out[key] = current
      elseif type(current) ~= "table" then
        out[key] = Logic.CopyTable(defaultValue)
      else
        out[key] = Logic.MergeDefaults(current, defaultValue)
      end
    elseif current == nil then
      out[key] = defaultValue
    else
      out[key] = current
    end
  end
  return out
end

function Logic.IsForever(interfaceVersion)
  return interfaceVersion == 16001
end

function Logic.HealthBelow(current, maxHealth, percent, secret)
  if secret then
    return false
  end
  if type(current) ~= "number" or type(maxHealth) ~= "number" or maxHealth <= 0 then
    return false
  end
  return (current / maxHealth) * 100 < percent
end

function Logic.IsHealthBarKey(key)
  if type(key) ~= "string" then
    return false
  end
  local lower = string.lower(key)
  if not string.find(lower, "health", 1, true) then
    return false
  end
  if string.find(lower, "power", 1, true) or string.find(lower, "cast", 1, true) or string.find(lower, "absorb", 1, true) then
    return false
  end
  return true
end

function Logic.PlayedSummary(records)
  local account = 0
  local byClass = {}
  if type(records) ~= "table" then
    return { account = 0, byClass = byClass }
  end
  for _, record in pairs(records) do
    if type(record) == "table" and type(record.totalSeconds) == "number" and type(record.classFile) == "string" then
      account = account + record.totalSeconds
      byClass[record.classFile] = (byClass[record.classFile] or 0) + record.totalSeconds
    end
  end
  return { account = account, byClass = byClass }
end

function Logic.ClassFraction(classSeconds, accountTotal)
  if type(classSeconds) ~= "number" or type(accountTotal) ~= "number" or accountTotal <= 0 then
    return 0
  end
  return classSeconds / accountTotal
end

function Logic.FormatDuration(seconds)
  if type(seconds) ~= "number" then
    return "\226\128\148"
  end
  local whole = math.floor(seconds)
  local hours = math.floor(whole / 3600)
  local minutes = math.floor((whole % 3600) / 60)
  if hours > 0 then
    return string.format("%dh %dm", hours, minutes)
  end
  return string.format("%dm", minutes)
end

function Logic.FormatClock(elapsed)
  if type(elapsed) ~= "number" or elapsed < 0 then
    elapsed = 0
  end
  local whole = math.floor(elapsed)
  return string.format("%02d:%02d", math.floor(whole / 60), whole % 60)
end

function Logic.AnchorSide(menuLeft, panelWidth, gap)
  gap = gap or 12
  if menuLeft < panelWidth + gap then
    return "RIGHT"
  end
  return "LEFT"
end

function Logic.CanRequestPlayed(now, lastRequest)
  if lastRequest == nil then
    return true
  end
  return (now - lastRequest) >= 60
end

function Logic.AfkBlocked(state)
  if not state.enabled or not state.isAFK then
    return true
  end
  if state.locked or state.cinematic or state.movie or state.casting then
    return true
  end
  return false
end

function Logic.AfkSuppressed(now, suppressUntil)
  return type(suppressUntil) == "number" and now < suppressUntil
end

return Logic
```

local ADDON = ...
RakaMod = RakaMod or {}
local Logic = RakaMod.Logic or dofile("Logic.lua")
RakaMod.Logic = Logic

local DEFAULTS = {
  overlay = { enabled = true, collections = true, played = true, professions = true },
  reveal = { enabled = true, casting = true, health = true, healthPercent = 90, mouseover = true, combat = true, pet = false },
  zoneText = { enabled = true, size = 32, r = 1, g = 1, b = 1, outline = "OUTLINE" },
  afk = { enabled = true, cameraPan = true },
  gradient = {
    enabled = false,
    left = { r = 0.91, g = 0.84, b = 0.64 },
    right = { r = 0.15, g = 0.14, b = 0.13 },
  },
  played = {},
}

local Core = {}
RakaMod.Core = Core
local modules = {}
local loginDone = false
local missingPrinted = false
local lastPlayedRequest = nil

function Core:IsForever()
  local _, _, _, interfaceVersion = GetBuildInfo()
  return Logic.IsForever(interfaceVersion)
end

function Core:AddonLoaded(name)
  return C_AddOns and C_AddOns.IsAddOnLoaded and C_AddOns.IsAddOnLoaded(name)
end

function Core:CanRequestPlayed(now)
  return Logic.CanRequestPlayed(now, lastPlayedRequest)
end

function Core:NotePlayedRequest(now)
  lastPlayedRequest = now
end

local function sectionEnabled(def)
  local section = RakaMod.db[def.dbKey]
  if type(section) ~= "table" or section.enabled ~= true then
    return false
  end
  if def.requires and not Core:AddonLoaded(def.requires) then
    return false
  end
  return true
end

function Core:ApplyModule(def)
  if sectionEnabled(def) then
    if not def._enabled and def.OnEnable then
      def._enabled = true
      def:OnEnable()
    end
  elseif def._enabled and def.OnDisable then
    def._enabled = false
    def:OnDisable()
  else
    def._enabled = false
  end
end

function Core:RegisterModule(def)
  modules[#modules + 1] = def
  if def.OnLoad then
    def:OnLoad()
  end
  if loginDone then
    self:ApplyModule(def)
  end
end

function Core:RefreshModules()
  for _, def in ipairs(modules) do
    self:ApplyModule(def)
  end
end

function RakaMod.OpenSettings()
  if RakaMod.Settings and RakaMod.Settings.Show then
    RakaMod.Settings:Show()
  end
end

local frame = CreateFrame("Frame")
frame:RegisterEvent("ADDON_LOADED")
frame:RegisterEvent("PLAYER_LOGIN")
frame:SetScript("OnEvent", function(_, event, name)
  if event == "ADDON_LOADED" and name == ADDON then
    if not Core:AddonLoaded("EllesmereUI") then
      if not missingPrinted then
        print("RakaMod requires EllesmereUI.")
        missingPrinted = true
      end
      return
    end
    RakaModDB = Logic.MergeDefaults(RakaModDB, DEFAULTS)
    RakaMod.db = RakaModDB
  elseif event == "PLAYER_LOGIN" then
    if not RakaMod.db then
      return
    end
    RakaMod.sessionStart = GetTime()
    RakaMod.playedThisSession = false
    loginDone = true
    Core:RefreshModules()
    if Core:CanRequestPlayed(GetTime()) then
      RequestTimePlayed()
      Core:NotePlayedRequest(GetTime())
    end
  end
end)

SLASH_RAKAMOD1 = "/rakamod"
SLASH_RAKAMOD2 = "/rmod"
SLASH_RAKAMOD3 = "/rm"
SlashCmdList.RAKAMOD = function()
  RakaMod.OpenSettings()
end

local function PickColor(target, onChange)
  local previous = { r = target.r, g = target.g, b = target.b }
  local function write(r, g, b)
    target.r, target.g, target.b = r, g, b
    onChange()
  end
  if ColorPickerFrame.SetupColorPickerAndShow then
    ColorPickerFrame:SetupColorPickerAndShow({
      r = target.r, g = target.g, b = target.b, opacity = 1, hasOpacity = false,
      swatchFunc = function()
        local r, g, b = ColorPickerFrame:GetColorRGB()
        write(r, g, b)
      end,
      cancelFunc = function()
        write(previous.r, previous.g, previous.b)
      end,
    })
  else
    ColorPickerFrame.func = function()
      local r, g, b = ColorPickerFrame:GetColorRGB()
      write(r, g, b)
    end
    ColorPickerFrame.cancelFunc = function()
      write(previous.r, previous.g, previous.b)
    end
    ColorPickerFrame:SetColorRGB(target.r, target.g, target.b)
    ColorPickerFrame:Show()
  end
end

`Enable` creates the frames once.

Panel: 300 wide, strata `FULLSCREEN_DIALOG`, frame level 20. Three font-string blocks: Collections, Played, Professions. Each block is a header plus up to six rows. Played also has up to 13 statusbars, one per class file that has stored time, using `RakaMod.Media.StatusbarPath` and `RAID_CLASS_COLORS`.

Hook `GameMenuFrame` `OnShow` and `OnHide`. On show, if `RakaMod.db.overlay.enabled`, call `Refresh` and show the dim and the panel. On hide, hide both.

`Refresh` placement:

```lua
local side = RakaMod.Logic.AnchorSide(GameMenuFrame:GetLeft() or 0, 300, 12)
panel:ClearAllPoints()
if side == "LEFT" then
  panel:SetPoint("RIGHT", GameMenuFrame, "LEFT", -12, 0)
else
  panel:SetPoint("LEFT", GameMenuFrame, "RIGHT", 12, 0)
end
```

Collections rows, each hidden when its function is missing:

- Mounts: `C_MountJournal.GetMountIDs` and `GetMountInfoByID`. Count ids whose 11th return is true over the total.
- Toys: `C_ToyBox.GetNumLearnedToys` over `C_ToyBox.GetNumToys`.
- Pets: `C_PetJournal.GetNumPets` returns owned, total.
- Achievement points: `GetTotalAchievementPoints`.

Hide the collections header when every row is hidden.

Played:

- Session is `GetTime() - RakaMod.sessionStart`, formatted with `FormatDuration`.
- Character total is `RakaMod.db.played[UnitGUID("player")].totalSeconds`, or an em dash from `FormatDuration(nil)`.
- Account total and class bars come from `PlayedSummary`. A bar width is `260 * ClassFraction`. Hide a class with no seconds.
- On show, if `RakaMod.playedThisSession` is false and `CanRequestPlayed(GetTime())`, call `RequestTimePlayed()` and `NotePlayedRequest(GetTime())`.
- Register `TIME_PLAYED_MSG` while enabled. The handler stores `name`, `realm`, `classFile`, `totalSeconds`, and `lastUpdated = time()` on the current GUID, sets `RakaMod.playedThisSession = true`, then refreshes if the panel is shown. Do not call `RequestTimePlayed` from the message handler.

Professions: if `GetProfessions` is missing, hide the header and rows. Otherwise read every non-nil index from `GetProfessions()`. `GetProfessionInfo` returns name, icon, skillLevel, maxSkillLevel. If `EllesmereUIDataBars` is loaded, use an icon from `_G.EllesmereUIDataBars_ProfessionIcons[name]` or `EllesmereUIDataBars.ProfessionIcons[name]` when that lookup succeeds.

### Task 6: Player frame reveal

**Files:**
- Create: `Reveal.lua`
- Modify: `RakaMod.toc`

**Interfaces:**
- Consumes: `RakaMod.Core:RegisterModule`, `RakaMod.db.reveal`, `RakaMod.Logic.HealthBelow`
- Produces: `RakaMod.Reveal:Update`

- [ ] **Step 1: Write `Reveal.lua`**

Insert it after `Overlay.lua`. `requires = "EllesmereUIUnitFrames"`.

Player global: `EllesmereUIUnitFrames_Player`. Pet global: `EllesmereUIUnitFrames_Pet`. Pet is evaluated only when `RakaMod.db.reveal.pet` is true.

Alpha target: `frame._visWrap or frame`. Ellesmere fades the player frame through that wrapper. Store and restore `IsShown` / `GetAlpha` on the alpha target. Force-show always sets that target's alpha to `1`. When unlocked, also `Show` the unit frame itself.

Events while enabled: `UNIT_HEALTH`, `UNIT_MAXHEALTH`, `UNIT_SPELLCAST_START`, `UNIT_SPELLCAST_STOP`, `UNIT_SPELLCAST_CHANNEL_START`, `UNIT_SPELLCAST_CHANNEL_STOP`, `UNIT_SPELLCAST_INTERRUPTED`, `UNIT_SPELLCAST_FAILED`, `PLAYER_REGEN_DISABLED`, `PLAYER_REGEN_ENABLED`. Ignore unit events whose unit is not `player`.

Mouseover: hook the player frame `OnEnter` and `OnLeave` once. A local `hovering` flag drives the mouseover trigger.

Secret check:

```lua
local function IsSecret(value)
  if issecretvalue and issecretvalue(value) then
    return true
  end
  if canaccessvalue and not canaccessvalue(value) then
    return true
  end
  return false
end
```

Health trigger uses `UnitHealth("player")` and `UnitHealthMax("player")` with `Logic.HealthBelow` and `RakaMod.db.reveal.healthPercent`. If either number is secret, the health trigger is false.

Casting trigger: `UnitCastingInfo("player")` or `UnitChannelInfo("player")`. Combat trigger: `UnitAffectingCombat("player")` or `InCombatLockdown()`.

Active means the corresponding db switch is true and the condition is true.

For each watched frame, keep `cycle = { active = false, shown = nil, alpha = nil }`.

When any active trigger is true:

- On the first force of a cycle, store `IsShown()` and `GetAlpha()` from the alpha target before changing it.
- `SetAlpha(1)` on the alpha target. While unlocked, also `Show` the unit frame. While locked, skip `Show`.
- Secure combat driver: Ellesmere only writes `state-visibility` while unlocked, and `RegisterStateDriver` during lockdown does not stick. When `reveal.combat` is on and the frame is not locked, install `RegisterStateDriver(frame, "visibility", "[combat] show")` as soon as any trigger is active, so the driver is armed before combat. Mark `drivers[frame] = true` only on success. While locked, still try the install, but do not treat a failed call as installed.
- After Ellesmere runs `UpdateFrameVisibility`, an active cycle would lose its alpha. Ellesmere's combat and roster handler calls a local function, so a `hooksecurefunc` on the module-table `UpdateFrameVisibility` is not enough. While a cycle is active, also `hooksecurefunc` the alpha target's `SetAlpha` once per target: if the cycle is still active and the new alpha is not `1`, immediately `SetAlpha(1)` again with a recursion guard. Optionally keep the module-table visibility hook as a second re-apply.

When no active trigger is true:

- If this module installed a driver (`drivers[frame]`), and unlock allows it, `UnregisterStateDriver(frame, "visibility")`, then set `frame._euiVisDriver = nil`, then call `EllesmereUI._ModuleNS.EllesmereUIUnitFrames.UpdateFrameVisibility` when that function exists. Do not apply the stored alpha after that call.
- If this module did not install a driver, do not clear `_euiVisDriver`. Still prefer `UpdateFrameVisibility` when it exists.
- If `UpdateFrameVisibility` is missing, when unlocked restore the stored shown flag with `Show` / `Hide` on the unit frame, and restore the stored alpha on the alpha target.
- Clear the cycle.

`Disable` runs the release path, unhooks nothing that would error, and unregisters the events.

### Task 8: AFK screen

**Files:**
- Create: `AFK.lua`
- Modify: `RakaMod.toc`

**Interfaces:**
- Consumes: `RakaMod.db.afk`, `RakaMod.Logic.AfkBlocked`, `RakaMod.Logic.AfkSuppressed`, `RakaMod.Logic.FormatClock`, `RakaMod.Media.FontPath`
- Produces: `RakaMod.AFK:Enter`, `RakaMod.AFK:Leave`

- [ ] **Step 1: Write `AFK.lua`**

Insert it after `ZoneText.lua`. `requires = nil`.

State locals: `active`, `suppressUntil`, `startedAt`, `castRetry`, `cameraOn`, `enteredByKey`.

Events: `PLAYER_FLAGS_CHANGED`, `PLAYER_REGEN_DISABLED`, `LFG_PROPOSAL_SHOW`, `UPDATE_BATTLEFIELD_STATUS`.

On `PLAYER_FLAGS_CHANGED` for `player`, call `Consider`. `Consider` uses:

```lua
local blocked = RakaMod.Logic.AfkBlocked({
  enabled = RakaMod.db.afk.enabled,
  isAFK = UnitIsAFK("player"),
  locked = InCombatLockdown(),
  cinematic = CinematicFrame and CinematicFrame:IsShown(),
  movie = MovieFrame and MovieFrame:IsShown(),
  casting = UnitCastingInfo("player") or UnitChannelInfo("player"),
})
local suppressed = RakaMod.Logic.AfkSuppressed(GetTime(), suppressUntil)
```

If blocked because of a cast, and the flag is still AFK, schedule one `C_Timer.After(30, Consider)` if `castRetry` is false, then set `castRetry` true. Other blocked reasons do not schedule that retry. If not blocked and not suppressed and not `active`, call `Enter`. If the player is no longer AFK and `active`, call `Leave(false)`.

`Enter`:

- `CloseAllWindows()`
- `UIParent:Hide()`
- Show a fullscreen frame, mouse and keyboard enabled, frame strata `FULLSCREEN_DIALOG`.
- `OnKeyDown`: if the key is `PRINTSCREEN`, call `Screenshot()` and return. Any other key calls `Leave(true)`.
- Model frame: `pcall` `SetUnit("player")`, animation `67`, then `C_Timer.After(2.3, function() if model then model:SetAnimation(0) end end)`. A model error leaves the text up.
- Name line: `UnitName("player")` plus realm from `GetRealmName()`.
- Guild line: `GetGuildInfo("player")` as `guild-rank`, or `No Guild`.
- Timer font string updated by `C_Timer.NewTicker(1, ...)` with `FormatClock(GetTime() - startedAt)`.
- Chat frame: register `CHAT_MSG_WHISPER`, `CHAT_MSG_BN_WHISPER`, `CHAT_MSG_GUILD`. Add the sender and message. Keep the last 500 lines.
- If `cameraPan` is true, `pcall(MoveViewLeftStart, 0.03)` and set `cameraOn` from the pcall result.

`Leave(fromKey)`:

- Cancel the ticker and the model timer.
- If `cameraOn`, `pcall(MoveViewLeftStop)` and clear `cameraOn`.
- Unregister the three chat events and clear the chat text.
- Hide the AFK frame and `UIParent:Show()`.
- If `fromKey`, set `suppressUntil = GetTime() + 60`.
- If not `fromKey`, set `suppressUntil = nil`. The screen stays down until the AFK flag turns off and on again, because `Consider` only enters when it is not already active and a later flag change is required. Store `holdUntilFlag` true on a non-key leave, and have `Consider` return while that flag is set and `UnitIsAFK("player")` is still true. Clear `holdUntilFlag` when the player is not AFK.

`PLAYER_REGEN_DISABLED`, `LFG_PROPOSAL_SHOW`, and `UPDATE_BATTLEFIELD_STATUS` when `GetBattlefieldStatus(arg1) == "confirm"` call `Leave(false)` if `active`.

`OnDisable` calls `Leave(false)` if `active`.

- Produces: `RakaMod.Gradient:Apply`, `RakaMod.Gradient:Enable`, `RakaMod.Gradient:Disable`

- [ ] **Step 1: Write `Gradient.lua`**

Insert it after `AFK.lua`. `requires = nil`. `OnEnable` returns immediately when Unit Frames, Raid Frames, and Nameplates are all not loaded. The settings note from Task 4 already explains that case. When at least one is loaded, enable and scan the frames that exist.

Known unit globals, scanned only when Unit Frames is loaded:

- `EllesmereUIUnitFrames_Player`
- `EllesmereUIUnitFrames_Pet`
- `EllesmereUIUnitFrames_Target`
- `EllesmereUIUnitFrames_Focus`
- `EllesmereUIUnitFrames_TargetTarget`
- `EllesmereUIUnitFrames_Boss1` through `EllesmereUIUnitFrames_Boss8`

Raid scan, only when Raid Frames is loaded. Do not walk `_G` by the `EllesmereUIRaidFrames` prefix. Party and raid health is not on the button; it is `GetFFD(button).health`. Use:

```lua
local rf = EllesmereUI and EllesmereUI._ModuleNS and EllesmereUI._ModuleNS.EllesmereUIRaidFrames
local buttons = rf and (rf._allButtons or (rf._internals and rf._internals.allButtons))
local getFFD = rf and (rf.GetFFD or (rf._internals and rf._internals.GetFFD))
if buttons and getFFD then
  for i = 1, #buttons do
    local data = getFFD(buttons[i])
    local health = data and data.health
    if health and health.GetObjectType and health:GetObjectType() == "StatusBar" then
      RakaMod.Gradient:Hook(health)
    end
  end
end
```

Nameplate scan, only when Nameplates is loaded. Do not scan Blizzard plates from `C_NamePlate.GetNamePlates()` for the visible bar. Use Ellesmere's plate table:

```lua
local np = EllesmereUI and EllesmereUI._ModuleNS and EllesmereUI._ModuleNS.EllesmereUINameplates
local plates = np and np.plates
if plates then
  for _, plate in pairs(plates) do
    local health = plate and plate.health
    if health and health.GetObjectType and health:GetObjectType() == "StatusBar" then
      RakaMod.Gradient:Hook(health)
    end
  end
end
```

Also listen for `NAME_PLATE_UNIT_ADDED` and rescan plates. Keep `GROUP_ROSTER_UPDATE` for the raid button list.

Unit-frame scanner, depth limit 3, for the known unit globals only:

```lua
local function Scan(object, depth, found)
  if not object or depth > 3 or found[object] then
    return
  end
  found[object] = true
  if type(object) ~= "table" or not object.GetObjectType then
    return
  end
  for key, value in pairs(object) do
    if RakaMod.Logic.IsHealthBarKey(key) and type(value) == "table" and value.GetObjectType and value:GetObjectType() == "StatusBar" then
      RakaMod.Gradient:Hook(value)
    elseif type(value) == "table" and value.GetObjectType and depth < 3 then
      Scan(value, depth + 1, found)
    end
  end
end
```

`Hook` runs once per bar, marked with `bar.RakaModHooked = true`. Store `bar.RakaModOriginalColor = bar.SetStatusBarColor`. Replace `SetStatusBarColor`:

```lua
function bar:SetStatusBarColor(r, g, b, a)
  bar.RakaModLastColor = { r, g, b, a }
  bar.RakaModOriginalColor(bar, r, g, b, a)
  if RakaMod.db.gradient.enabled then
    RakaMod.Gradient:Paint(bar)
  end
end
```

`Paint` reads the left and right db colors and calls `GetStatusBarTexture():SetGradient("HORIZONTAL", CreateColor(left...), CreateColor(right...))` inside `pcall`. A failure skips that bar.

`Apply` walks the hooked bar list and calls `Paint` on each while enabled.

`Disable` restores `SetStatusBarColor` to `RakaModOriginalColor` and calls it with `RakaModLastColor` when that color exists. It does not write Ellesmere saved variables. Clear the hooked list.

Also rescan on `GROUP_ROSTER_UPDATE` and `NAME_PLATE_UNIT_ADDED`. Do not use `OnUpdate`.
